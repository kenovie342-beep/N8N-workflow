# n8n Automation Suite (add-on)

An independent add-on that sits **beside** an unmodified n8n. It adds: central LLM provider settings, eight social
platform modules, a persistent job queue with enforced concurrency, a DB-backed scheduler (default timezone
Africa/Lagos), a GitHub Actions execution engine, a Cloudflare Worker control plane, importable n8n workflows and a
monitoring dashboard. n8n itself is not changed or replaced.

```
 n8n (unchanged) --HTTP + X-Addon-Token--> Suite API (FastAPI) --> PostgreSQL
                                              |  queue worker (max concurrency enforced in DB)
                                              |  scheduler (next_run_at persisted)
                                              +--> LLM APIs / social APIs (credentials decrypted only at call time)
                                              +--> GitHub Actions (workflow_dispatch with job_id only) --signed callback--> Suite
 Cloudflare Worker (D1 + R2 + cron) <--- optional public ingress for callbacks, signed R2 URLs, scheduler nudge
```
